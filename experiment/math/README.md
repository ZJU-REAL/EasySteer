# Math steering experiment

## Latest results

These results were generated by `evaluate.ipynb` with vLLM 0.29.0. The model
and software versions differ from the original paper environment.

Hardware and software:

- NVIDIA RTX 6000D
- vLLM 0.29.0 with PyTorch 2.13.0+cu130
- `math-verify` 0.9.0
- `deepseek-ai/DeepSeek-R1-Distill-Qwen-1.5B` in BF16

The evaluation uses all 500 MATH500 questions and all 1,319 GSM8K test
questions. Both conditions use the same engine, the paper's explicit reasoning
prefix, greedy decoding (`temperature=0`), and an 8,192-token limit. vLLM's
default execution mode is used. SEAL adds `execution - reflection - transition`
at layer 20 with scale 0.5 on paragraph-break tokens.

| Dataset | Questions | Baseline accuracy | SEAL accuracy | Baseline mean tokens | SEAL mean tokens |
|---|---:|---:|---:|---:|---:|
| MATH500 | 500 | 63.80% | 68.60% | 4,488.8 | 3,633.6 |
| GSM8K | 1,319 | 75.06% | 80.74% | 2,749.5 | 1,688.5 |

## Notebooks and code

- `evaluate.ipynb` runs baseline and SEAL evaluation and prints aggregate
  accuracy and generation-length metrics. Per-question outputs are written to
  the ignored `.runtime/` directory.
- `data_construction.ipynb` rebuilds the three reasoning vectors from 1,000
  MATH training traces. The committed `*_avg_vector.gguf` files can be reused
  for evaluation.
- `common.py` contains the shared prompt construction and answer scoring.

## Evaluation data

Download [MATH-500](https://huggingface.co/datasets/HuggingFaceH4/MATH-500) and
[GSM8K](https://huggingface.co/datasets/openai/gsm8k) once:

```python
import json
from pathlib import Path

from datasets import load_dataset

datasets = {
    "math500": load_dataset("HuggingFaceH4/MATH-500", split="test"),
    "gsm8k_test": load_dataset("openai/gsm8k", "main", split="test"),
}
for name, rows in datasets.items():
    Path(f"{name}.json").write_text(json.dumps(list(rows), ensure_ascii=False))
```

Set `EASYSTEER_DATA_DIR` when the JSON files are stored elsewhere. Set
`EASYSTEER_LIMIT` to a positive integer for a smaller local check; the default
runs the complete datasets.

## Rebuilding vectors

Place `math_train_1000.json`, a JSON list of the 1,000 MATH training problems,
in the data directory. The construction notebook captures classified
paragraph-break rows in small batches, accumulates category sums, and exports
one vector for each category. Use the same model for construction and
evaluation. The training subset and generated traces are not distributed here.
